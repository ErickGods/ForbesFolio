## 🎯 Descrição

Portfolio pessoal construído como uma revista digital interativa, onde cada projeto é uma "página" que pode ser folheada com animações realistas de virar página. O diferencial é o pipeline CI/CD completo que demonstra boas práticas de DevOps.

O projeto conta com GitHub Actions para lint, validação de dados e build automatizado em cada PR, além de deploy automático para GitHub Pages ao fazer merge na main. Um sistema de templates padroniza a adição de novos projetos.

| Tecnologia | Uso |

## 📊 Métricas / Resultados

- 🔄 Pipeline CI/CD com 3 workflows automatizados
- 📋 Templates padronizados para issues e PRs
- ✅ Validação automática de dados de projetos
- 🚀 Deploy automático em cada merge
