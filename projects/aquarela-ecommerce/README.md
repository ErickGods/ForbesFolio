## 🎯 Descrição

Desenvolvimento full-stack de uma plataforma de e-commerce para a marca de joias Aquarela/BYDIO. O projeto inclui catálogo de produtos com categorias, carrinho de compras, checkout completo com integração ao gateway de pagamento AbacatePay, e painel administrativo.

O backend foi construído com Laravel, incluindo API RESTful, gestão de sessões stateless, serviço de pagamento integrado e sistema de notificações. O frontend conta com interface responsiva, mock data para desenvolvimento e fluxo de compra otimizado.
