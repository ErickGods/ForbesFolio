## 🎯 Descrição

Desenvolvimento de um portal web para avaliações esportivas, permitindo que personal trainers gerenciem seus atletas, registrem avaliações físicas e acompanhem a evolução dos treinos.

O projeto utiliza Next.js 15 com App Router para o frontend, Supabase como backend-as-a-service (autenticação, banco de dados e storage), e Tailwind CSS v4 para estilização. Inclui sistema de autenticação com diferentes níveis de acesso (admin, personal trainer, atleta).
