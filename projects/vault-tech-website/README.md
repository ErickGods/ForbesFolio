## 🎯 Descrição

Redesign completo do website corporativo da Vault Tech, uma empresa de tecnologia. O projeto envolveu a modernização da identidade visual, substituindo ícones baseados em emoji por assets SVG profissionais e minimalistas, implementando imagens 3D com efeito glassmorphism.

O resultado foi um site premium com estética corporativa de alto nível, responsivo e otimizado para performance, incluindo páginas de serviços, cases de sucesso e institucional.
